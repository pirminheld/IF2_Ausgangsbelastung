# Eine LED zu viel? – IF2
Interaktiver Einstieg zu Ausgangsbelastbarkeit und Fan-out.
Online: https://pirminheld.github.io/IF2_Ausgangsbelastung/
Offline: index.html per Doppelklick öffnen. Alle benötigten Dateien liegen lokal.
Ablauf: LED zuschalten, Vermutungen sammeln, Belastung aufdecken und Auslegung verändern.
Oben: QR-Code vergrößern und Beameransicht. Unten: vollständiges Zurücksetzen.
Der Fehlerfall oben ist vorgegeben. Die veränderbare Rechnung darunter prüft ausschließlich das statische LOW-Strombudget; keine analoge Schaltungssimulation.
Daten: TI SN74LS00, SDLS025D, Abschnitte 6.3/6.6. LED-Strom als Modellannahme.
Impressum/Nutzung: impressum.html. Keine externen Skripte oder Tracking.
